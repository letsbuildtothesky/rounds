## Reproduce

For native contracts also run tools/generate_v23_device_wire.py and tools/generate_v23_local_schema.py. Set ROUNDS_TEST_FLUTTER_BIN to the explicit existing Flutter binary when running tools/verify_v23_checkpoint.py to include native identity/preservation/encryption and SQLCipher process-kill checks plus SDK version; absent runtime is explicitly NOT_RUN. Also set ROUNDS_TEST_BUILD_ANDROID=1 to compile/check the ARM64 debug APK and verify its SQLCipher packaging without installing it. Mobile vault/encryption/backup verification is a separate device gate.

For an intentional source change: edit owning sections and dependent contracts/acceptance together. Run tools/generate_v23_command_mirrors.py FIRST because it normalizes OpenAPI bytes; only afterward regenerate pickup/command metadata, pickup/device/execution/native-command wire closures and the local-schema mirror. Then run the Operations static-validator generator against the final pickup wire. Check every generator with --check before the expensive aggregate; a source-hash-only change still invalidates earlier closures. Refresh working manifests with tools/refresh_v23_manifests.py; freeze source/code/tools while running tools/verify_v23_checkpoint.py, then run tools/spec_audit_v23.py and tools/check_build_specs_v23.py. Do not treat an interrupted run or evidence from earlier file hashes as a pass. tools/reconcile_v23.py records the R1-specific corrections, not a general editor: do not blindly rerun it over later product decisions.

tools/render_build_readiness_v23.py renders module cards and verifies baseline paths. tools/verify_v23_checkpoint.py records actual local validators/tests and separates NOT_RUN from PASS. It starts temporary native PostgreSQL and HTTP fixtures on loopback and therefore needs local listener permission. It does not execute HTML, connect to configured Supabase Auth or send provider/customer actions. Full PostGIS needs the specified local runtime; browser/device acceptance still requires its appropriate environment. Do not work around the previous local-browser policy denial.
