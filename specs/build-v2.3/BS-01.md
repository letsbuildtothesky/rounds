## Configuration mechanics

Use dedicated typed editors, not an arbitrary JSON textbox. SavePolicy validates its discriminator and immutable version; current bindings update under expected version. All16 policy families are retained. First-tenant setup has explicit city/site/timezone/currency/proof/configuration steps; missing approved proof, retention or money rules stays incomplete with a specific configuration path. Never substitute demo IDs or guessed tariffs.

Resolve declared scope specificity and reject ambiguous equal-specificity bindings. Policy snapshots follow the owning product rule: committed promises/proof/accepted commercial terms retain history; current permissions and unsent privacy requirements are rechecked. Save switches show pending/confirmed/rejected; structured forms preserve drafts on validation/conflict. Keep-editing/discard works for Escape, city/section switch, drawer close and reload where persistence is promised.

Feature disable stops new work controls but leaves existing assignments, accepted agreements, custody, returns and history reachable. Tenant suspension likewise requires supervised active-work recovery. Platform support is explicit time-limited reasoned access, not a hidden global admin bypass. Connection configured and provider verified are different statuses.
