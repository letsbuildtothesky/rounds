## Four independent truths

Mapbox draws Operations; server owns plan sequence/estimates; Google embedded navigation guides Driver; Rounds records authorised observations. Reuse current map/controller/telemetry primitives only after revalidating those boundaries. Provider path differences are expected and must not be hidden with invented geometry. Routing adapter returns provider/profile/display_surface/geometry availability, time/distance/freshness/traffic/restriction warnings; unavailable is not zero. Do not draw Google Routes geometry on Mapbox as a shortcut. Current account terms/SDK support require official verification before implementation, not inherited dated prose.

## Operations controls

Reproduce Phase39 map-view drawer and selected states: Operations/satellite/site/3D, tilt2D/3D, rotation±20°, North, zoom/fit/focus/back, traffic, rainAuto/On/Off, supply and entrance inspection. See DISPATCH-SECTIONS. Camera updates use geographic coordinates; clean up markers/listeners; selected work survives supported style changes. Traffic layer and traffic-aware ETA are separately labelled. Attribution/vendor safety controls remain unobscured.

Weather requires a configured real provider, coverage, observation/forecast time and expiry. Missing/stale is unavailable/stale, not sunny. Auto only highlights relevant conditions; no fabricated blue rain rectangles. Independent buffer has a specific reason and bounded policy; do not add generic rain delay to traffic already accounting for congestion. Vehicle-safety rule opens action or proposes compatible capacity, never auto-broadcasts.

Entrance review preserves original address/private unit notes, tenant-scoped reusable access facts and reviewed revision. Optional GPS observation does not auto-approve an entrance. Street View uses configured authorised surface with no-imagery/error/map fallback; loaded iframe is not verification. Preserve pending edits across provider failure.

## Driver/telemetry

Navigation intent keyed by driver+stop+destination version+provider; remount reuses intent where SDK permits. Real destination change uses acknowledgement/consent before replacement. Measure actual SDK requests separately; do not promise billing dedupe.

Validate collection entitlement and exact tenant tracking grant, device/sequence/time/accuracy, ≤500-sample batch and per-sample outcomes. Older uploads may enrich permitted history but cannot rewind current position. Coalesce scoped Broadcast hints; gap/reconnect refetches authoritative snapshot. Revocation ends exact access; approximate freelancer supply never reveals off-duty GPS. Missing approved raw-history retention disables that capture while allowed current-position operation may continue.

## Acceptance

AC-07/11 and P10/E06 cases. All map controls change actual map state, return restores selection/drafts and markers remain anchored through pan/zoom/rotation. Inject provider/rain/traffic failure and stale location. On supported iPhone, mainstream Android and aggressive-OEM Android run navigation+telemetry+camera/mic/dialer together, including2-hour locked/battery-saver/weak-network/restart and wrong-turn scenarios. Capture measured freshness/battery/heat and report PASS/BRIDGE REQUIRED/NAVIGATION FAILURE/LOCATION DESIGN FAILURE. Emulator/script success cannot pass this field gate.
