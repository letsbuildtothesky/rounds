## Changelog

- 1.0 (2026-09-08): reconcile v2.3-r1 rules, ground retain/adapt/replace work in baseline code, and separate implementation readiness from acceptance and release gates.

## Data and authority

One global driver principal with separate employer relationship, voluntary contact permissions, eligibility and commitments. Reuse existing auth/session widgets only through the new model. OTP belongs to the approved Auth adapter, with abuse limits and useful expiry/retry without account enumeration. Signed invitations bind actual tenant/role to authenticated identity; a query-string company name grants nothing. No production skip-login/debug success button.

A01 routes after actual startup/session/locale readiness, never animation timeout. A01B selection commits on Continue; preserve existing preference and pending work. A02–A05 original-group layout requires targeted approval for visual refresh. A06 Team and A06B independent paths remain distinct; five A07 display vehicles do not assert navigation/cargo legality. Profile draft survives restart; persisted fields follow contract, not freeform screen labels.

## Workforce

Save recurring shift templates and dated occurrences separately from attendance. Bind actual vehicle to driver/date/time, with sorted guard/exclusion checks for concurrent overlap. Break/no-show/availability changes invalidate affected plan inputs. Archive leaves historical identity and is blocked/recovered with unresolved work. Never delete assigned vehicle to resolve capacity.

StartShift is explicit and policy-bounded. Home distinguishes idle, staged, assigned, ending soon/overtime and ended; no timer clocks in/out. EndShift checks open custody/assignment or explicit recovery. RequestAttendanceCorrection records proposed interval/reason; manager decision appends amendment, preserving original events. Hours, scheduled time and money are different facts. Include employer relationship chat with no Round; don't force a fake active stop to contact Operations.

## R3-only capabilities

Network onboarding/identity/license/liveness/payout captures require provider/policy approval. Submitted is receipt, not verified; corrections replace requested evidence only and unknown submission reconciles original application. A09 animation cannot claim liveness. Availability open/paused/later/accepted/stale is driver-controlled, with deadline and commitment checks. End team shift never automatically opens Network. Ask/ReplyAvailability means interest only, not acceptance/tracking grant. Relationship chat needs separate opt-in.

## UI and acceptance

Canonical A/B/K00/L files plus Phase39 Drivers/vehicle/date/settings surfaces. Shared components may serve several states but every state gets a reference/evidence row. Implement accessible edit/discard and present actual date-specific work; selected empty date must not copy today's fixture hours.

Source P06 acceptance plus AC-07/10. Invalid/revoked/used invite never joins wrong business; interrupted entry resumes original principal. Concurrent vehicle binding has one winner. Clock-out lost response reconciles, unreturned goods block end shift, corrections don't change delivery history. R3 tests include paused/off-duty no GPS leakage, expired availability reply, verification callback for old application and account change with pending evidence. Native permissions are queried from OS, never flipped by Recheck UI alone.
