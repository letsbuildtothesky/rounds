## Proposed module work

Replace plan-and-approve RPC semantics with separate GeneratePlan, PreviewPlanMove, ApplyPlanProposal, SavePlan, StagePlan and ReleasePlan handlers. Reuse capacity helpers only after multi-dimension, return/reload and dated-shift tests. Maintain one plan per tenant/city/date, immutable proposal ID/version1 plus independent base_version/input/policy hash/expiry. Do not equate proposal version with plan version.

Plan with reviewed points, promises, actual shift occurrences/vehicle bindings, hard cargo constraints, existing commitments and required return/reload. Unknown route estimates are unknown, never zero travel. A deterministic feasible initial sequence is acceptable in R1; don't claim global optimisation. Generated proposals are previews, not accepted operational assignments.

## State and command rules

Save stores draft plans. Stage publishes provisional own-team work/reserves busy range while goods can still be inbound. Release authorises selected ready Rounds and creates/reuses assignment/release snapshots with events atomically. Departure gate is synchronously derived in the same affecting transaction, never asynchronously unlocked by worker. Priority: blocked → discrepancy → awaiting receipt → awaiting preparation → ready.

For incomplete D1 plus complete D2, explicit route/assignment adjustment can retain onlyD2; no implicit skip on batch pickup and no subset ofD1. Current/performed/in-custody steps cannot be ordinary drag moves. Preview every affected driver/vehicle timeline, return/reload/free-after, lateness and following Rounds; apply only against unchanged roots/hash.

Team instructions require acknowledgement; cannot_comply opens operator action and blocks departure without deleting assignment. Freelancer material changes require consent to exact amendment; zero fee delta does not waive it. Pause is operational_hold, not fictional paused lifecycle. Active cancellation requires goods disposition and contractual resolution. Reassignment after pickup cannot impersonate physical transfer.
