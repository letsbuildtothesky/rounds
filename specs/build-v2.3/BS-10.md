## Search and acceptance

Operator StartBroadcast targets eligible voluntarily open freelancers regardless of own-fleet capacity. Select deliveries, whole units or existing Round exclusively; validate same city/date/pickup and claims under locks. Unplanned selection atomically creates search Round/stops/claims. Existing released/in-custody work needs explicit recovery, not removal via broadcast. Snapshot approved fare/radii/wave windows/scope/hash. Missing tariff/search policy returns configured error, not an invented default.

Workers advance nearest-first waves using server time/eligibility/current revisions. Offer status is server fact; pending-accept UI is not persisted accepted state. RespondOffer acceptance locks broadcast/claims/global driver interval and creates one immutable agreement, acknowledged freelance-origin assignment, released Round/stops, commitment and open settlement. Return IDs usable by GetDriverRound immediately; no Team plan/release or second acceptance is required. Goods can remain unready and pickup stays blocked. Losers become taken and gain no private assigned data.

Restart closes old search identity and requires no unresolved agreement/claim conflict. Stop/decline/expire doesn't erase historical offered work. Availability interest/chat permission is not acceptance or GPS entitlement.

## Accepted work and money

Material changes require exact amendment consent, including removing an incomplete order. Zero fare delta does not waive consent. Decline/expiry preserves original scope; team acknowledgement is not a substitute. Whole-order rule remains in every branch, no partial approval or residual job creation. Cancellation requires actual custody disposition and applicable accepted compensation.

Keep settlement lifecycle, earning state, payment state and dispute case independent. Money is integer minor units plus one currency. RecordSettlement appends actual external payment/refund evidence; it never calls bank/payment execution or marks work earned. Same external reference/command cannot add twice. Due/refund_due derive from approved entitlement and net paid; prepaid-but-unearned is valid. Close only with final entitlement, no unresolved finance case and balanced due/refund obligations. No automatic percentage fee/wallet/COD.

Financial dispute adjusts authorized entitlement without changing valid proof. Evidence dispute needs proof-review authority and genuine same-handoff replacement; finance can't create photographs or reverse physical history. Usage charges require selected event+approved tariff+unique receipt, never offer retries as fee triggers.
