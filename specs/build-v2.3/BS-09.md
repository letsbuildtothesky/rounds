## History projections

Implement GetHistory/Delivery as scoped projections over actual events and snapshots, with stable IDs, filters/as_of and definitions for each metric. Reuse existing export/history presentation where matching Phase39, but replace old outcome assumptions. Distinguish handoff pending proof, fully evidenced delivery, cancellation, return and reschedule. Ratios disclose numerator/denominator/exclusions; unknown is not zero. Incident cause records confirmed/reported/inferred/under-review provenance. CorrectIncidentCause appends actor/reason correction; don't overwrite original event or score freelancer declines as failures.

RequestExport creates asynchronous scoped snapshot with private output, hash/cutoff/filter metadata and current access check at download. Escape CSV formula-looking values. Revoke future download after membership/token revocation; already downloaded copies cannot be recalled. Never put permanent signed URLs to unrelated media in exported rows.

## Source adapters

All sources use canonical intake; UrbanFlowers is the pilot connection, not a bypass. Save configuration independently from actual verified connection status. Intake/writeback/tracking/exception permissions are separate. Manual Add Delivery remains available if sources are off.

First-party `/v1/integrations/{connection_id}/events` verifies the specified HMAC over timestamp/newline/eventID/newline/raw-body, server time window, bounded payload and active connection. Same connection/event/hash replays receipt; changed hash conflicts. Persist receipt before202, normalize asynchronously. Native WooCommerce/Shopify callbacks need their own verified adapters/signature fixtures before they reach this boundary; no session-auth fallback or assumed signing format.

Older revisions cannot replace reviewed address/loaded manifest. Source changes after commitment produce review/explicit changes. Outbound mapping is declared per provider capability; delivered writeback consumes delivery.completed only. Unknown provider effect reconciles original reference before retry; disconnect pauses effects, not physical completion. Reconnect cannot replay stale overwrite over newer external truth.

## Public tracking/customer channels

Use audience-scoped hashed expiring/revocable tokens and dedicated exchange/query, not tenant/user API auth. Buyer and recipient surprise permissions differ. Exclude other stops, private route/internal notes and uncontrolled driver contact. ETA freshness and evidence-pending states match current authorised facts.

Email/SMS/LINE enqueue from exact eligible event+audience+channel+kind, freeze template and revalidate unsent privacy. Provider-accepted/delivered/read remain distinct. Enable real channels only with configured provider, privacy and approved copy; fixture checks cannot send to customers.
