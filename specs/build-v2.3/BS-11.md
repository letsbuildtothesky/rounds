## Required records and roles

Implement trip/booking/load/receipt/inbound dependency commands and projections through shared transaction runner. Use explicit authenticated transport driver and named destination receiver/site grants; dispatcher cannot impersonate receiver. Trip booking reserves capacity, not custody. Origin actual load and departure validate quantities/preparation and disposition; no ETA or animated truck implies physical receipt. Support supplied typed trip lifecycle without inventing extra closed states.

Create/link each local delivery once. Destination local pickup is destination hub. Optional capability hides new-work Intercity controls without removing existing in-flight custody/history. No temperature sensor/cold-chain certification or country expansion is inferred from this module.

## Morning planning contract

At07:00 before truck arrives09:00, build R1(D1–D3) and R2(D4–D5), assign and stage. Preserve exact routes/stops through delay. Operator sees expected inbound quantities, hub/ETA and affected promises, can explicitly preview/reallocate future team work while preserving freelancer consent. Stage is visibility/reservation; release is departure authority.

ReceiveTrip records positive increments against booked line balance, same manifest/header, correct site/actor and actual condition. Receive2 then3 of5 totals5; same command replays0, another1 rejects. No cumulative input accidentally adds twice. Missing/wrong/damaged creates discrepancy, not ready status. Whole delivery must be completely received/prepared before local pickup, but independent complete orders can proceed after explicit plan adjustment.

With D1/D2/D4/D5 received, R2 is ready while R1 names missingD3. Gate changes synchronously under command locks even if workers are paused. LaterD3 updates same delivery/stop identity, not duplicate intake. CloseTrip requires all booked balances/evidence/dispositions resolved. Partial return/transfer receipts preserve actual custody; no auto residual delivery.

## Acceptance

All P08 cases plus AC-10/15. J06 with two cities, two receivers, delayed truck, wrong-manifest line, repeated receipt, concurrent receipt/release and independent ready route. Deny origin dispatcher without receiving grant. Cancellation after load cannot close without each balance disposition. Disable Intercity mid-trip: no new trips, current recovery/history remain authorised. No fake truck movement on stale telemetry; route/provider estimates and observation freshness remain distinct.
