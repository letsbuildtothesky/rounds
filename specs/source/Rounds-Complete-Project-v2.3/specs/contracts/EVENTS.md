# Event facts — V2.3

One event per fact/subject/version. Row changes participating in one fact are coalesced. Multiple independent facts may commit together. Each consumer has an explicit event and dedupe rule. Worker events identify worker_run_id; user-command events identify command_id. No generated singularized table/state event aliases remain.
